# Organizador de Tarefas

Projeto simples criado para praticar o gerenciamento
de configuração utilizando Git e GitHub.

## Objetivo

Organizar uma lista de tarefas e praticar o controle
de alterações nos arquivos do projeto.

## Arquivos

- tarefas.py: código simples que exibe uma lista de tarefas.
- README.md: documentação do projeto.
